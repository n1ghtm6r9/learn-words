# Переработка движка обучения — дизайн

Дата: 2026-08-18

## Цель

Заменить текущий движок обучения (SM-2, единый режим Study, Dashboard, Статистика) на модель, заданную пользователем:

1. Добавление слова (перевод) — уже есть, остаётся.
2. Массовое добавление нескольких пар слово-перевод за один раз.
3. Обучение новых слов через две фазы с настраиваемым числом повторов.
4. Раздел «Повторение» с рейтингом слова 0–100 (🔴🟡🟢) и алгоритмом забывания, который сам решает, как часто слово должно всплывать.
5. Всё, что не входит в этот список и не является чистым UX (тема, TTS, визуальный стиль), — убрать.

Технологии, тестовый стек, Dexie/React/Zustand/Tailwind/shadcn/Motion — без изменений, только модель данных и экраны.

## Модель данных

```ts
interface Word {
  id?: number;
  term: string;
  translation: string;
  createdAt: number;

  stage: 'new' | 'review';

  // актуально только при stage === 'new'
  learningPhase: 'A' | 'B';
  phaseStreak: number;        // подряд верных/почти-верных в текущей фазе; сбрасывается на 0 при ошибке

  // актуально только при stage === 'review'
  rating: number;              // 0–100, значение НА МОМЕНТ lastReviewedAt (не текущее эффективное)
  reviewStreak: number;        // подряд верных/почти-верных ответов в Повторении — двигает период полураспада

  lastReviewedAt?: number;     // когда последний раз отвечали (в любой фазе/режиме)
}
```

Таблица `words` в Dexie индексируется по `stage` (нужна быстрая выборка "все новые" / "все на повторении"):
`words: '++id, term, stage'`.

**Миграция существующих данных** (Dexie version bump 1 → 2, апгрейд-функция, не потеря данных):
- `reviews` — удаляется (`reviews: null` в новой версии stores).
- Каждое существующее слово получает `stage: 'review'`, `learningPhase: 'B'`, `phaseStreak: 0`, `reviewStreak: 0`, стартовый `rating` — эвристика по старому `interval` (≥21 → 80, ≥6 → 60, иначе → 40), затем удаляются старые поля SM-2.

## Алгоритм рейтинга и забывания (раздел «Повторение»)

Экспоненциальный распад к нулю с периодом полураспада, растущим от `reviewStreak` — чем увереннее слово отвечалось подряд, тем медленнее оно тускнеет со временем без повторения:

```
halfLifeDays(reviewStreak) = 2 + reviewStreak * 3       // дней
effectiveRating(word, now) =
  round(clamp(
    word.rating * 0.5 ** ((now - word.lastReviewedAt) / DAY_MS / halfLifeDays(reviewStreak)),
    0, 100
  ))
```

Если `lastReviewedAt` не задан (слово только что перешло в Повторение и ещё не открывалось в этом режиме) — `effectiveRating = word.rating` без распада.

**Обновление при ответе в Повторении** (после вычисления `effectiveRating` на момент ответа):
- `correct` → `rating = min(100, effectiveRating + 15)`, `reviewStreak += 1`
- `almost` → `rating = min(100, effectiveRating + 5)`, `reviewStreak = 0`
- `wrong` → `rating = max(0, effectiveRating - 25)`, `reviewStreak = 0`
- `lastReviewedAt = now` в любом случае.

**Цветовые пороги:** `effectiveRating >= 67` → 🟢 зелёный; `>= 34` → 🟡 жёлтый; иначе → 🔴 красный.

**Очередь Повторения:** все слова `stage === 'review'`, отсортированные по возрастанию `effectiveRating(word, now)` (самые "красные"/забытые — первыми). Очередь фиксируется в начале сессии (один проход, без пересчёта на лету) — предсказуемо, как в прежнем Study. Верхнего лимита на размер очереди нет: чем хуже помнится слово, тем ближе оно к началу списка, и так каждый раз, когда пользователь открывает раздел.

## Обучение новых слов (раздел «Новые слова»)

**Настройки** (раздел «Настройки», два независимых ползунка, хранятся в localStorage через Zustand, по умолчанию 3): `phaseARepeats`, `phaseBRepeats`.

- **Фаза A** (`learningPhase === 'A'`): показываем слово И перевод вместе. Пользователь вводит слово. `correct`/`almost` → `phaseStreak += 1`; как только `phaseStreak >= phaseARepeats` → `learningPhase = 'B'`, `phaseStreak = 0`. `wrong` → `phaseStreak = 0` (фаза не откатывается).
- **Фаза B** (`learningPhase === 'B'`): показываем только перевод. Пользователь вводит слово. `correct`/`almost` → `phaseStreak += 1`; как только `phaseStreak >= phaseBRepeats` → слово переходит в `stage: 'review'`, `rating: 70`, `reviewStreak: 0`, `learningPhase`/`phaseStreak` перестают использоваться. `wrong` → `phaseStreak = 0`.

**Очередь новых слов — интерливинг, а не блоками.** Все слова `stage === 'new'` загружаются в пул и перемешиваются один раз в начале сессии. Каждый шаг показывает следующее слово пула по кругу (курсор `% длина пула`), поэтому одно и то же слово не встречается два раза подряд — это резко эффективнее для запоминания, чем зубрить одно слово N раз без остановки. Слово, только что перешедшее в `review`, удаляется из пула. Сессия заканчивается, когда пул пуст (все слова выучены) — экран с confetti и количеством выученных слов.

## Общий компонент карточки

Фаза B и Повторение идентичны по механике (показать перевод → ввести слово → нечёткое сравнение → фидбек → далее) — один компонент `RecallCard` используется в обоих местах. Фаза A — отдельный `RecognitionCard` (показывает и слово, и перевод). Оба переиспользуют `lib/fuzzyMatch.ts` и `lib/tts.ts` без изменений.

Состояние сессии (пул/курсор для новых слов, очередь/индекс для повторения) живёт **локально в компоненте** (`useState`, инициализация из Dexie при монтировании), а не в глобальном сторе — уход с экрана просто размонтирует компонент и сбрасывает сессию, без риска «залипшей» сессии в сторе (это реальный баг, который был в предыдущей версии и который эта архитектура исключает по конструкции).

## Массовое добавление

Один экран «Добавить» с переключателем режима «Одно слово» / «Список». Режим «Список» — textarea, одна пара на строку. Строка разбирается по первому вхождению любого из разделителей `- – — = : <tab>`; всё до разделителя (обрезанное) — слово, всё после — перевод. Строки без разделителя или с пустой частью — невалидны. Перед сохранением показывается превью разобранных пар (валидные — с возможностью посмотреть/поправить, невалидные — подсвечены с объяснением) и кнопка «Сохранить всё». Дубликаты по `term` (без учёта регистра) — предупреждение в превью, не блокировка (та же политика, что у одиночного добавления). Каждое сохранённое слово создаётся с `stage: 'new', learningPhase: 'A', phaseStreak: 0`.

## Экраны и навигация

Нижняя навигация, 5 пунктов: **Новые слова** · **Повторение** · **Добавить** · **Слова** · **Настройки**. Экран по умолчанию при открытии приложения — «Новые слова» (это то, что пользователь просил делать "здесь и сейчас").

1. **Новые слова** — сессия интерливинга (см. выше). Пусто → «Нет новых слов» + кнопка «Добавить». По исчерпании пула — экран итогов с confetti: сколько слов выучено за сессию.
2. **Повторение** — сессия с очередью по рейтингу. Пусто → «Пока нечего повторять — сначала выучите новые слова» + кнопка «Новые слова». По прохождении всей очереди — экран итогов с confetti: верно/почти/неверно (тот же формат, что был в старом SessionSummary).
3. **Добавить** — одиночная форма (как сейчас) + массовый режим.
4. **Слова** — список всех слов, поиск, редактирование (без сброса `stage`/`rating`), удаление. Для `stage: 'new'` — бейдж «Новое · Фаза A/B». Для `stage: 'review'` — цветная точка 🔴🟡🟢 + числовое значение эффективного рейтинга.
5. **Настройки** — два ползунка (`phaseARepeats`, `phaseBRepeats`), диапазон 1–10, значение сохраняется сразу.

## Тестирование

- `lib/rating.ts` (расчёт `effectiveRating`, обновление рейтинга по вердикту) — юнит-тесты на все три исхода и на распад по времени/streak, это критичная логика.
- `lib/parseWordLines.ts` (разбор массового ввода) — юнит-тесты на разные разделители, пустые строки, строки без разделителя.
- Компоненты сессий — smoke-тест на полный цикл (Фаза A → Фаза B → переход в Повторение; отдельно — прохождение одного слова в Повторении).
- Остальное (`WordForm`, `WordList` и т.д.) — существующие тесты адаптируются под новые поля, без изменения объёма покрытия.

## Вне рамок

- Никакой синхронизации, бэкенда, авторизации — как и раньше.
- Никакого возврата слова из Повторения обратно в «Новые слова» — низкий рейтинг просто держит слово в начале очереди Повторения.
- Понятие "сессии повторения ограниченного размера" не вводим — очередь всегда полная, отсортированная.
